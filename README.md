# Database Projects (MS Access / MySQL Concepts)

## Overview

This repository contains a set of database projects that I created while learning database design and SQL concepts.

The projects are implemented using **MS Access (.accdb)**, but they follow core **MySQL/database principles** such as tables, relationships, and queries.

---

## Projects Included

### 1. Student Management System

Manages student information and course registrations.

**Main Tables:**

* Students
* Courses
* Enrollments

**Features:**

* Stores student details
* Links students to courses
* Displays enrolled courses using queries

---

### 2. Library System

A database for managing books and borrowing activities.

**Main Tables:**

* Books
* Members
* Loans

**Features:**

* Tracks borrowed books
* Links members to books
* Displays active loans

---

### 3. Sales Tracking System

Tracks customers, products, and orders.

**Main Tables:**

* Customers
* Products
* Orders
* OrderDetails

**Features:**

* Records customer purchases
* Calculates total sales using queries
* Shows order history

---

### 4. Inventory System

Manages stock and suppliers.

**Main Tables:**

* Products
* Suppliers
* Stock

**Features:**

* Tracks product quantities
* Links products to suppliers
* Displays available stock

---

### 5. Hotel Booking System

Handles room bookings and guest information.

**Main Tables:**

* Guests
* Rooms
* Bookings

**Features:**

* Stores guest details
* Manages room bookings
* Displays booking records

---

### 6. Employee Records System

Stores employee and department information.

**Main Tables:**

* Employees
* Departments
* Salaries

**Features:**

* Links employees to departments
* Stores salary information
* Displays employee records

---

## What I Learned

* How to design relational databases
* Creating tables with primary and foreign keys
* Building relationships between tables
* Writing SQL queries (SELECT, JOIN, GROUP BY)
* Organising data efficiently

---

## Tools Used

* MS Access (.accdb)
* SQL (MySQL concepts)
